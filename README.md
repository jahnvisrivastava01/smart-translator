# 🌍 Smart Translator

A modern AI-powered multilingual translator built using Python and CustomTkinter.

Smart Translator allows users to translate text between multiple languages with a clean futuristic interface and built-in pronunciation support.

---

# ✨ Features

- 🌐 Multilingual Translation
- 🔊 Text-to-Speech Pronunciation
- 🔄 Swap Languages Instantly
- 📋 Copy Translation
- 🎨 Modern Dark UI
- ⚡ Fast Translation System
- 🖥️ Desktop Application
- 🇫🇷 French Language Support

---

# 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/jahnvisrivastava01/smart-translator.git
```

Move into project folder:

```bash
cd smart-translator
```

Install dependencies:

```bash
pip install customtkinter deep-translator gtts pygame
```

Run the application:

```bash
python main.py
```
